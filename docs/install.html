Install guide

Installing Lagoon on your TV

Lagoon is not in the Google Play Store, so it is installed from its APK file. This is called sideloading. It takes a few minutes the first time, and updates work the same way. Pick whichever method suits you:

Downloader app (easiest) Send from your phone ADB from a computer Amazon Fire TV

The download link is always the newest release:

https://github.com/JTCozart/lagoon-tv/releases/latest/download/lagoon-tv.apk
Menu names differ a little between TV makers and Android versions. If a setting is not exactly where these steps say, look for the same words under Settings > Apps or Settings > System.

Before you start: allow installing apps

Android only installs apps from outside the Play Store when you give a specific app permission to do it. On newer Google TV devices that option is hidden until developer options are turned on.

  1. Open Settings > System > About.
  2. Scroll to Android TV OS build (or Build) and press Select on it seven times, until a message says you are now a developer.
  3. Go back to Settings > Apps > Security & restrictions > Unknown sources. On some devices this is under Settings > Privacy > Security & restrictions.
  4. Turn it on for the app you will install Lagoon with, such as Downloader or your file manager. You can turn it off again once Lagoon is installed.

Method 1: the Downloader app (easiest)

Downloader is a free app built for exactly this. Everything happens on the TV.

  1. On the TV, open the Play Store, search for Downloader by AFTVnews and install it.
  2. Allow Downloader to install unknown apps, as described in Before you start.
  3. Open Downloader. In the address box, type the download link above and choose Go.
  4. When the download finishes, choose Install, then Done.
  5. Downloader offers to delete the APK file. You can say yes; Lagoon stays installed.

Method 2: send it from your phone

Handy if typing a long address with a remote is a chore.

  1. Install Send files to TV (or a similar file transfer app) on both your phone and the TV.
  2. On your phone, open the download link above to save lagoon-tv.apk.
  3. Open the transfer app on both devices, choose Receive on the TV and Send on the phone, and pick the APK.
  4. On the TV, open the received file from a file manager that you have allowed to install unknown apps, and choose Install.

Method 3: ADB from a computer

For people comfortable with a command line. ADB is part of Google's free Android SDK Platform Tools.

  1. Turn on developer options on the TV, as in Before you start.
  2. In Settings > System > Developer options, turn on USB debugging or Network debugging. Newer Google TV devices call it Wireless debugging.
  3. Find the TV's IP address under Settings > Network & Internet, on your current network.
  4. On the computer, connect to the TV. On devices with Wireless debugging, first choose Pair device with pairing code on the TV and pair using the address and code it shows: 
    adb pair 192.168.1.50:37425
    Then connect, using the address shown on the Wireless debugging screen (older devices use port 5555): 
    adb connect 192.168.1.50:5555
  5. Accept the Allow debugging? prompt that appears on the TV.
  6. Download the APK on the computer and install it: 
    adb install -r lagoon-tv.apk
    The -r flag lets the same command update an existing install.

Amazon Fire TV

Lagoon is built for Android TV and Google TV. Fire TV runs a version of Android, so it should work there too, but it has not been tested.

  1. Go to Settings > My Fire TV > About and select your device name seven times to show developer options.
  2. Go to Settings > My Fire TV > Developer options > Install unknown apps and turn it on for Downloader.
  3. Install Downloader from the Amazon Appstore and follow Method 1.

First start

  1. Open Lagoon from your apps. It may sit at the end of the apps row the first time.
  2. Enter your Jellyfin server address, for example https://jellyfin.example.com or 192.168.1.20:8096 on your home network.
  3. Sign in with your user name and password, or choose Quick Connect: Lagoon shows a code, and you approve it from the Jellyfin app or website on another device.

Updating

Lagoon checks for a new release by itself when the home screen opens, at most twice a day. When one is out it shows what changed and offers Update now: it downloads the APK, checks it against the published checksum, and opens Android's installer. The first time, Android may ask you to allow Lagoon to install apps; allow it, then choose Update now again. Not now hides that version until the next one.

You can also install the newest APK the same way you installed Lagoon, over the top of the old one. Your sign-in and settings are kept. Each release is listed on the releases page with notes on what changed.

Checking the download

Every release includes a SHA256SUMS file. To confirm the APK you downloaded is the one the release published, compare its checksum:

sha256sum lagoon-tv.apk        # Linux and macOS
Get-FileHash lagoon-tv.apk     # Windows PowerShell
Only download Lagoon from this site or from the GitHub releases page. An APK from anywhere else could have been changed.

Troubleshooting

"App not installed" or "There was a problem parsing the package"

The download may be incomplete; delete it and download again. If you previously built Lagoon yourself, uninstall that copy first, because a differently signed version cannot be installed over it.

The Install button is greyed out or nothing happens

The app you are installing from has not been allowed to install unknown apps. See Before you start.

Lagoon cannot find my server

Check the address works in a web browser on the same network, include the port if your server uses one (Jellyfin's default is 8096), and make sure the TV is on the same network when using a local address.
